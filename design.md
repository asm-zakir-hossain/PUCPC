# UI/UX Design Specification
## Prime University Computer Programming Club (PUCPC) Website

**Design Inspiration:** https://www.ideo.com/  
**Design Style:** Modern, bold typography, interactive, storytelling-driven  
**Version:** 1.0  
**Date:** 2026-04-29  

---

## 1. Design Philosophy

The PUCPC website will follow a design inspired by IDEO:

- **Minimal but bold**
- **Large typography**
- **Strong visual hierarchy**
- **Smooth scrolling experience**
- **Image and content storytelling**
- **Clean whitespace usage**
- **Modern interactive feel**

The site should feel:
👉 Premium  
👉 Alive  
👉 Professional  
👉 Tech-focused  

---

## 2. Overall Layout Concept

### Structure

- Sticky Navigation Bar (minimal)
- Full-width sections
- Scroll-based storytelling
- Card-based content blocks
- Smooth transitions

---

## 3. Color System

### Primary Colors
- Black: `#0B0B0B` (background / text)
- White: `#FFFFFF` (text / sections)

### Accent Colors (choose 1–2)
- Blue: `#2563EB`
- Purple: `#7C3AED`
- Cyan: `#06B6D4`

### Secondary
- Light Gray: `#F5F5F5`
- Dark Gray: `#1F2937`

---

## 4. Typography

### Font Style
- Headings: Bold, modern sans-serif (e.g., Inter, Poppins)
- Body: Clean sans-serif

### Hierarchy
- H1: Very large (48px–72px)
- H2: 32px–40px
- H3: 20px–24px
- Body: 16px–18px

### Style Rules
- Use large headlines like IDEO
- Minimal text, high impact
- Strong contrast
